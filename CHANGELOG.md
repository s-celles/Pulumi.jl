# Changelog

All notable changes to Pulumi.jl will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Core SDK types: `Resource`, `CustomResource`, `ComponentResource`, `ProviderResource`, `ResourceOptions`, `URN`
- `Output{T}` parametric type with `apply`, `all`, `secret` support
- Resource registration: `register_resource`, `component`, `register_outputs`, parallel registration
- Dependency graph with cycle detection and topological sort
- `Config` type with typed accessors (`get_int`, `get_bool`, `get_float`, `get_object`)
- Context management: `get_stack`, `get_project`, `get_organization`, `is_dry_run`
- Stack exports: `export_value`, `export_secret`
- Provider function invocation: `invoke`, `call`
- Logging via Pulumi engine: `log_debug`, `log_info`, `log_warn`, `log_error`
- Error types: `PulumiError`, `ResourceError`, `GRPCError`, `ConfigMissingError`, `DependencyError`
- gRPC clients for ResourceMonitor and Engine services
- LanguageRuntime gRPC server with handlers for Pulumi CLI integration
- Protobuf serialization/deserialization with secret envelope handling
- Retry logic with exponential backoff for transient gRPC errors
- Proto file management via Julia Artifacts
- Documentation site via Documenter.jl
- CI via GitHub Actions
- `Language Host` documentation guide covering plugin port discovery, the
  implemented `LanguageRuntime` RPCs and the environment `Run` sets up
- `Internals` documentation page covering the non-exported API
- `llms.txt` and `llms-full.txt`, generated by the documentation build and
  published with the documentation site
- `justfile` with the main entry points (tests, docs, proto regeneration,
  language host)
- `upstream-bugs.md` recording the gRPCServer.jl and ProtoBuf.jl limitations
  Pulumi.jl works around
- Dependabot configuration, and TagBot and CompatHelper workflows

### Fixed

- `create_language_runtime_server` no longer throws on its documented default
  `port = 0`; an ephemeral port is now bound as the Pulumi plugin protocol
  requires
- `start_and_print_port!` announces the port actually bound instead of a
  hard-coded `50051`, so the Pulumi CLI can connect to a host started on an
  ephemeral port
- `service_descriptor` no longer passes the runtime as a reflection file
  descriptor, which made server creation fail with the released gRPCServer.jl
- `Run` reads the project, stack and organization from the request instead of
  fields that do not exist on `JuliaLanguageRuntime`, which silently left the
  execution context unconfigured; `PULUMI_ORGANIZATION` is now set as well
- `InstallDependencies` actually runs `Pkg.instantiate()` for the program's
  environment, in a separate process, and streams its output to the CLI
- `GetProgramDependencies` reports the program's real dependencies, read from
  its `Project.toml` and resolved `Manifest.toml`, instead of a hard-coded entry
- Duplicate docstring on the `Output` constructors, which emitted a
  "Replacing docs" warning at precompilation

### Changed

- The documentation build no longer allows `missing_docs` and `docs_block`
  warnings; every documented symbol is now referenced from the manual
- `docs/Project.toml` resolves Pulumi.jl through a relative `[sources]` entry,
  so installing the documentation environment no longer records an absolute path
